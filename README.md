# VMS RSUD HAMBA — Frontend

Vendor Management System (PO → Approval PPK → BAST → Invoice & SP2D) — HTML/CSS/JS vanilla, backend Google Apps Script (REST JSON).

- Satu-satunya file yang perlu diedit: `js/config.js` → isi `GAS_URL` dengan URL `/exec` Apps Script.
- Deploy: push isi folder ini (dengan `index.html` di root) ke GitHub Pages / Netlify / Vercel.
- Panduan lengkap: `PANDUAN-INSTALASI.md`.

Struktur: `index.html` · `css/style.css` · `js/config.js, ui.js, store.js, api.js, app.js, pages-utama.js, pages-transaksi.js, pages-admin.js`
